🎄 The Great Christmas Garden Escape 🎄

Santa's Christmas garden has been locked down! The elves have scrambled the clues, the reindeer have eaten the map, and the garden gate won't open. Solve the horticulture puzzles, crack the codes and save Christmas!

🗝️ Your mission

Work through six rooms in order. Each has three puzzles. Solve them, work out the 3-digit code and unlock the next room.

Team rule: Work alone or with one partner. Record your answers and codes. No guessing codes!

Hints are available if you get stuck. Try to solve each puzzle before opening its hint.

🎅 Your mission begins...

It is Christmas Eve at the North Pole. Santa's horticulture garden supplies herbs, fruit and flowers for the Christmas feast. The Grinch has scrambled the garden's security system.

Six security rooms stand between you and the Christmas garden key. Show that you understand plant needs, pollination, food chains, healthy soil, New Zealand plants and biodiversity.

How to escape

  1. Read each puzzle carefully.
  2. Choose the correct answer(s).
  3. Use the code instructions to turn your answers into three digits.
  4. Enter the code to unlock the next room.
  5. Keep a record of tricky questions.

🌱 Room 1: The Seed Store

The seed store is freezing. Three cabinets are locked. Answer the questions to find the first code.

A — Plant survival: Which list contains the things plants need to survive and grow?

Think about what a plant needs to make food, take in materials and grow healthily.

B — The plant's job: What do we call an organism, such as a green plant, that makes its own food?

In a food chain, this organism is usually at the beginning because it makes its own food.

C — The energy factory: What is the name of the process plants use to make their own food using sunlight?

The word starts with “photo”, meaning light.
🔐 Seed Store code

For each puzzle, count the correct answer's position: first = 1, second = 2, third = 3. Put the three numbers together.

🐝 Room 2: The Pollination Workshop

The elves are making seed packets, but the flower workshop has jammed. Solve the pollination puzzles to restart the machine.

A — Bee supplies: What do bees collect from flowers?

One is a sugary liquid; the other is a powder involved in plant reproduction.

B — What is pollination? Choose the best definition.

It involves pollen moving between parts of flowers.

C — The missing helpers: Select TWO important roles insects can play in an ecosystem.

Think about how insects help plants reproduce and how other animals use them as food.
🔐 Workshop code

A: correct answer position. B: correct answer position. C: number of correct choices.

🦌 Room 3: The Reindeer's Food Chain

The reindeer ate the food-chain diagram! Rebuild it and answer the questions.

A — Build the chain: Click the organisms in the correct order, starting with the producer.

Grass makes its own food. A caterpillar eats plants. A small bird can eat caterpillars.

B — The plant-eater: What is an animal called if it eats only plants?

The word contains “herb”, another word for a plant.

C — The hunter: What is a predator?

Think about the animal doing the hunting.
🔐 Reindeer code

A: number of organisms in the completed chain. B: correct answer position. C: correct answer position.

🪱 Room 4: The Soil Scientist's Shed

The soil lab is full of compost, leaves and wriggly worms. Identify the organisms and materials that help keep soil healthy.

A — Underground workers: Select TWO reasons earthworms are important for healthy soil.

Think about what worms do as they move through soil and feed on decaying material.

B — Nature's recyclers: What do we call organisms that break down dead plants and animals?

Their job is decomposition — breaking material down.

C — Compost ingredients: Which group could be used to make compost?

Compost is made from organic materials that can decompose.
🔐 Soil Shed code

A: number of correct statements. B: correct answer position. C: correct answer position.

🌳 Room 5: The New Zealand Native Forest

The path to Santa's greenhouse runs through a miniature New Zealand forest. The gate needs your knowledge of habitats, ecosystems and native plants.

A — Where does it live? What is a habitat?

A habitat is an organism's home or living place.

B — A bigger picture: Which statement best describes an ecosystem?

Think about living things plus non-living things such as water, soil and sunlight.

C — Native or introduced? A plant that occurs naturally in New Zealand is called…

It belongs naturally in this place, rather than having been brought from elsewhere.
🔐 Native Forest code

A, B and C: write the position of the correct answer for each puzzle.

🎄 Room 6: The Grinch's Biodiversity Vault

The final room! The Grinch has hidden the Christmas garden key behind three biodiversity challenges.

A — What is biodiversity?

“Bio” relates to life. Think about the variety of living things in a place.

B — Trouble in the garden: Which TWO actions could reduce biodiversity in a garden?

Think about actions that remove living spaces or harm organisms.

C — The disappearing insects: What could happen if all insects disappeared from an ecosystem?

Think about insects as food for other animals and as pollinators.
🔐 Final Vault code

A: correct answer position. B: number of correct actions. C: correct answer position.
